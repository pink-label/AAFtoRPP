Primera version de conversor de AAF a RPP.

El software permite crear una sesión de Reaper en base a un timeline de video exportado en formato AAF.
Se selecciona el archivo AAF y en esa misma carpeta se genera la sesion de Reaper lista para abrir y empezar a trabajar.
Fue probado con timelines exportadas de Davinci Resolve. Parece que funciona bien pero podria haber algun bug.

Se adjunta una version ejecutable para su uso en Windows.

Creado con Google Antigravity en 3 prompts, larga vida al dios Google y sus tecnologías mágicas.
